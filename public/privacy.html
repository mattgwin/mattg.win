Privacy Policy

Last updated 20 September 2026

This policy covers MG Automation, a personal Google OAuth application used by one person: Matt Gwin, the owner of this site. It is not a product, it has no customers, and it is not offered to anyone else.

What the app is

MG Automation connects Matt's own Google accounts to a personal note-taking and task system running locally on his own computers. It exists so that software can read his mail and calendar on his behalf and help him organise it. There is no hosted service, no sign-up, and no other users.

What data it accesses

Only data belonging to the Google accounts Matt explicitly authorises. Specifically:

  • Gmail (gmail.readonly, gmail.compose): reads message and thread content in order to summarise and categorise it, and creates draft replies.
  • Google Calendar (calendar.events): reads events to understand availability, and creates or updates events for planning.
  • Google Drive (drive.readonly, drive.file): reads file content and metadata when asked to reference a document.

What it does not do

  • It never sends email. Replies are written as drafts and only a human presses send.
  • It does not delete mail, and it does not mark anything as spam.
  • It does not transmit data to any third party beyond the AI model provider processing a given request.
  • It does not sell, rent, share or monetise data, in any form, ever.
  • It does not use data for advertising, profiling, or training any model.

Where data goes

Data is fetched on demand and used to produce notes, summaries and tasks that are stored in a private file vault on Matt's own machines, synced only between his own devices. Message content is passed to the AI model provider that handles the request, solely to generate that response, and is not retained by this app on any server. No database, analytics system, or logging service operated by this app stores Google user data.

Limited Use disclosure

MG Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Derived notes live in a personal file vault and are deleted by deleting the files. Access can be revoked at any time from Google Account permissions, which immediately and permanently ends the app's ability to read anything.
