MG Automation

A private tool that reads Matt Gwin's own Gmail, Google Calendar and Google Drive into a personal notes and task system running on his own computers.

What it is

MG Automation is a personal knowledge vault. Mail, calendar events and documents are read on demand, summarised, and filed as notes and tasks in a private file store that syncs only between Matt's own devices. It replaces the manual work of reading an inbox and turning it into a to-do list.

It is used by exactly one person, the owner of this domain. There is no sign-up, no hosted service, no other users, and nothing is offered to the public. This page exists because Google requires a published home page for the OAuth application behind it.

What it accesses, and why

  • Gmail — gmail.readonly to read messages and threads so they can be summarised and categorised, and gmail.compose to write replies as drafts. The app has no ability to send: a human opens the draft and presses send.
  • Google Calendar — calendar.events to read commitments when planning a day, and to create or adjust time blocks around them.
  • Google Drive — drive.readonly and drive.file to read a document's contents when a note needs to reference it.

What it will not do

  • Send email. Ever. Drafts only.
  • Delete mail, trash threads, or mark anything as spam.
  • Share, sell, rent or monetise data in any form.
  • Use any data for advertising, profiling, or training a model.

MG Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where data is stored

Nowhere this app operates. Content is fetched when a request is made, used to produce a note, and the note lands in a private file vault on Matt's own machines. There is no server, no database, and no analytics belonging to MG Automation that holds Google user data. Access can be withdrawn at any time from Google Account permissions.
